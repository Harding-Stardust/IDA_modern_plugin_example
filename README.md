# IDA_modern_plugin_example
This is an example of how to write a modern plugin for IDA Pro
It is just a little more verbose version of [IDAs own example](https://github.com/HexRaysSA/ida-sdk/blob/main/src/plugins/hello/pyhello.py)

There is also a [guide on how to write a Python plugin](https://docs.hex-rays.com/developer-guide/idapython/how-to-create-a-plugin)

All credits to [Elias Bachaalany](https://github.com/0xeb) and his video guide of [IDAPython: An in-depth introduction to plugins in IDAPython](https://www.youtube.com/watch?v=rG7ArXYzwqw)
